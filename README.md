## 当前内容

### day1：C# List\<T\> 与对象入门

- 控制台程序，演示 `Product` 对象的创建和 `List<Product>` 集合的基本使用。
- 技术栈：C#、.NET Framework 4.8
- 运行方式：使用 Visual Studio 打开 `day1.sln`，按 F5 运行。

程序会提示输入商品编号，然后通过 `FindProduct` 方法在商品列表中查找并输出完整商品信息。

```text
请输入商品编号: 1002
找到商品！
商品名称: 鼠标
价格: 99 元
库存: 100 件
```

如果输入的编号不存在，程序会提示“未找到”对应商品。
